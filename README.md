# Panthers & Eagles

Oak Grove (Mo.) R-VI district activities and Central Methodist University cheer and STUNT, in one list.

- **Live site:** https://transcend-this.github.io/og-cmu-events/
- **Data:** a snapshot copied from each school's public calendar; the date is shown at the top of the page. Always confirm with the school before going to an event.
- **What changed:** [CHANGELOG.md](CHANGELOG.md)
- **Making changes:** [CLAUDE.md](CLAUDE.md)
- **Run the checks:** `cd tests && npm install && node run_tests.js`

Not affiliated with Oak Grove R-VI or Central Methodist University.
